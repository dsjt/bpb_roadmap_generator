# BPB ロードマップジェネレーター

BackpackBattles のビルド進行を「ラウンド × アイテム」のグリッドで可視化するツールです。

🔗 **https://dsjt.github.io/bpb_roadmap_generator/**

## 主な機能

- **グリッド配置** — パレットからアイテムをドラッグ＆ドロップでセルに配置。配置済みアイテムはドラッグで移動、クリックで削除
- **ラウンド数設定** — R1〜R18 の範囲で列数を自由に変更
- **アイテム画像** — 主要アイテムの画像をデフォルトで収録。パレット行をホバーして 📷 ボタンから個別に上書きも可能
- **PNG 保存** — グリッドをそのまま画像としてダウンロード
- **URL 共有** — 配置状態を URL に変換してコピー。そのURLを開くと配置が再現される
- **自動保存** — 操作のたびにブラウザのローカルストレージへ自動保存

## 使い方

1. 左のパレットからアイテムを探し、右のグリッドへドラッグ＆ドロップ
2. アイテムに独自画像を設定したい場合は、パレット行をホバーして 📷 ボタンをクリック
3. 完成したら「PNG保存」でダウンロード、または「URLをコピー」で共有

## ローカルでの起動

サーバー不要で `index.html` をブラウザで直接開くか、任意のHTTPサーバーで配信してください。

```bash
python3 -m http.server 8080
```

## 技術スタック

- 静的 HTML / CSS / JavaScript（ビルドなし）
- [html2canvas](https://html2canvas.hertzen.com/) — PNG エクスポート
- GitHub Pages でホスティング
